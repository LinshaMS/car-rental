# DriveEase — Car Rental Website

DriveEase is a responsive car rental website built using HTML, CSS, and JavaScript. It allows users to explore available cars, compare rental prices, view vehicle details, and submit booking requests.

## Features

- Browse available vehicles
- Search and filter cars by category
- Sort cars by rental price
- View individual car details
- Submit booking requests with rental cost estimates
- Responsive design for desktop and mobile devices
- Contact and About pages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using the Live Server extension or open it in your browser.

## Note

This is a front-end demonstration project. Booking requests are stored locally in the browser; the website does not currently use a backend or database.
